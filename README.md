# polinema-produk-ubis

Katalog produk Unit Bisnis Polinema + landing page produk (HTML/CSS/JS statis).

- `index.html` – katalog (dibaca dari `data/products.json`)
- `products/<slug>/index.html` – landing page tiap produk
- Kontak WhatsApp: `assets/js/wa.js` dan `data/products.json`

## Tambah produk
1. Salin `products/do-it-start-a-business/` ke `products/<slug-baru>/` lalu ubah isinya.
2. Tambah entri di `data/products.json`.

## Jalankan lokal
`python3 -m http.server 8000`, buka http://localhost:8000
